# Reverse-Engineer Book 1 & Prep Book 2 for Publishing

## Goal

Use the installed **reverse-scaffold** plugin (the "storycraft-skills" — no tool by that literal name exists; this is its reverse-engineering toolchain) to:

1. **Reverse-engineer Book 1 (*The Annotated Murder*)** — frozen, published — into a fully structured scaffold that becomes the authoritative series reference going forward. Read-only toward `books/book-01/`.
2. **Reverse-engineer Book 2 (*The Botanical Confession*) before it publishes** — same pipeline, but findings become a fix worklist, since Book 2 is (per your framing and the repo evidence: unchecked KDP checklist, no recorded upload, remaster ledger `upload_ready: false`) still editable.
3. **Reconcile both against each other and the existing series-bible**, producing a must-fix-before-publish list for Book 2 and a pre-publish punch list.

## Defaults I'm proceeding on (adjust any of these)

- **Toolchain:** `reverse-scaffold` plugin (analyze-manuscript → import-manuscript, with manuscript-analyst / voice-profiler agents).
- **Book 2 is not live for sale yet.** Its ledger says `published` but nothing confirms an upload; this plan corrects that ledger.
- **Scaffold location:** `reverse/book-01/` and `reverse/book-02/` in this repo — each import creates a standalone project shape (`book.config.yaml`, `canon/`, `chapters/`, `STATE.yaml`, its own `AGENTS.md`), one per book, scoped so the root `CLAUDE.md` is never touched.

## Key facts the plan builds on

- Sources: `books/book-01/manuscript/ch-01..08.md` (~22.8k words) and `books/book-02/manuscript/ch-01..08.md` (~22.8k words). Book 1's manuscript includes the Oct 2026 audiobook continuity fixes (e.g., ch-02 "walk home"); the published EPUB predates them — we reverse-engineer the **current manuscript text** and record that provenance in the analysis report.
- Existing canon to reconcile against: per-book `bible/` dirs (production-era, richer in places than anything inferred) and `series-bible/` (premise, world, timeline, story-memory, voice-dna, 4 recurring-character files).
- The remaster worktree (`agent/blackwood-ridge-remaster`, unmerged, 29 commits ahead) already holds editorial audits and a validated Book 2 upload package blocked only on author decisions — we consume its findings, we don't merge it.
- Known Book 2 export defect: legacy combined export uses level-two chapter headings (recorded in remaster docs; fixed only in the remaster build).

## Phase 1 — Reverse-engineer Book 1 (reference-only)

Run `analyze-manuscript` (fiction) scoped to `reverse/book-01/`:

1. **Boundary detection:** `manuscriptkit.py` over the 8 chapter files; confirm unit count and carry any warnings forward as `BOUNDARY` items.
2. **manuscript-analyst pass** → writes `reverse/book-01/reverse-scaffold-analysis.md`: character roster, reconstructed timeline (story order vs told order), world rules, POV map, per-chapter retrofitted scene breakdowns. Every item tagged `CONFIRMED` (chapter-cited), `CANON GAP`, or `LOW CONFIDENCE`.
3. **voice-profiler pass** → fills only the Voice & Style Profile section: mechanical profile (POV, tense, dialogue tags), voice inconsistencies, 6–8 verbatim representative passages.
4. **⏸ Checkpoint — your review.** The skill design requires a human pass over the analysis report (especially Open Questions); unreviewed flags become ledger rows later. I'll summarize the flags and wait for your corrections.
5. **Run `import-manuscript`** into `reverse/book-01/`: `book.config.yaml` (narrative stats from actuals, banned lists empty — retrofit not prescription), populated `canon/characters.md`, `canon/timeline.md`, `canon/world-rules.md`, `voice-bible.md`, `voice-samples.md`, `STATE.yaml` (8 chapters, complete, `gate_passed: false`), 8 chapter packets (`chapters/ch01..08/` with verbatim `draft.md`, retrofitted `outline.md`, empty `gate-report.md`), `findings.yaml` (generated via `findings.py` from the report's flags), `promises.yaml` (open threads with `payoff_by_ch: "TBD"`), scoped `AGENTS.md`/`CLAUDE.md`.
6. **Activate & sample:** verify with `book_status.py`; optionally hand-gate 1–2 chapters with `gate-check` to prove the scaffold is usable, not just populated.
7. **Reconciliation pass (the real value):** cross-check the inferred canon against `books/book-01/bible/` and `series-bible/`; write `reverse/book-01/reconciliation.md` — where inference and production bible disagree, the production bible wins and the divergence is recorded; propose concrete enrichments to `series-bible/` (applied only with your approval).

Book 1's manuscript is never edited. All Book 1 findings land as reference documentation.
