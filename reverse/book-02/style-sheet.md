### Compound rulings — F021, author-approved 2026-10-12

Standing rule: **hyphenate only compound modifiers before a noun** ("late-spring
rain"); the open noun phrase is the default elsewhere. The open/hyphenated
alternation below is therefore **role-based, not drift** — do not "fix" it.
The checker will keep listing these pairs; this table is the ruling it defers to.

| Pair | Ruling |
|---|---|
| almost right / almost-right | Open everywhere as predicate ("the tea was almost right"); hyphenated only as modifier. **Registered motif** ("the almost-right tea") — the hyphenated modifier uses are motif phrasings. |
| coming apart / coming-apart | Open as verb phrase; hyphenated only as modifier ("the coming-apart had a taste" is a nominalization — keep). |
| end of / end-of | Open only. Hyphenated hits are inside longer compound modifiers; no standalone "end-of." |
| garden club / garden-club | Open as noun ("the garden club"); hyphenated only as modifier ("garden-club split"). |
| holding in / holding-in | Hyphenated when nominalized ("the holding-in"); open as verb ("holding in grief"). |
| late spring / late-spring | Open as noun; hyphenated only before a noun ("late-spring light"). Both forms legitimately occur. |
| might not / might-not | Open only as words; hyphenated hits are nominalized ("the might-not") — keep those. |
| not carrying / not knowing / not knitting / not looking / not quite | The **nominalized "the not-X" is always hyphenated** — it is the book's registered cataloguing construction (voice-dna free-indirect). Open verb forms stay open. |
| pulled up / setting down | Open as verb phrases; hyphenated only inside compound modifiers. |
| the door / the-door | "the-door" occurs once (ch08), inside a hyphenated compound modifier — not a standalone variant. No action. |
