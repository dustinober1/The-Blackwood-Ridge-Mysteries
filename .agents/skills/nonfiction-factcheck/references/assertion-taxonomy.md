## Assertion Taxonomy

Every factual sentence in a non-fiction chapter is one of these types. Identify the type before verifying — each type has its own evidence requirement.

| Type | Examples | Verification requires | Failure mode if skipped |
|------|----------|----------------------|-------------------------|
| Statistic | percentages, counts, effect sizes, p-values, dates | Exact numeric match + denominator + population | Wrong number published as fact |
| Direct quote | "..." attributed material | Verbatim match + attribution + context | Fabrication or misquote |
| Paraphrase | near-verbatim restatement presented as source's view | Source actually holds that view, in those terms | Stealth misquote |
| Causal claim | "X causes", "leads to", "drives" | Causal evidence (experiment, mechanism), not correlation | Correlation laundered as causation |
| Comparative claim | "more than", "faster", "higher" | Both sides of the comparison verified | Half-verified comparison |
| Superlative | "first", "only", "largest", "never" | Exhaustive check against corpus | False superlative |
| Definition | "X is", "X means" | Matches the book's locked defined terms | Definition drift |
| Historical claim | dates, events, sequences | Primary or secondary source in corpus | Presentist or invented history |
| Attribution | "Smith argues", "studies show" | Named source in corpus, holding that view | Phantom authority |
| Anecdote/case | specific case, example, vignette | Case exists in corpus with matching details | Invented or altered case |

## Calibrated Certainty Table

Match the chapter's language to the source's evidence strength:

| Evidence in source | Chapter may say | Chapter may NOT say |
|--------------------|-----------------|---------------------|
| RCT / strong causal design | demonstrates, establishes, causes | (nothing stronger needed) |
| Quasi-experimental | indicates, suggests | proves, causes |
| Correlational | predicts, associates with, correlates with | leads to, drives, causes |
| Single small-N study | preliminary evidence suggests | proves, establishes |
| Theoretical argument | implies, would predict, entails | shows, data prove |
| Expert opinion | thinks, argues, believes | research shows |

## Evidence Hierarchy

A claim is only as strong as the strongest corpus source that directly supports it:

1. Primary source in the corpus (study, document, interview, data)
2. Secondary source in the corpus explicitly citing the primary
3. Author-stated fact marked established in the chapter plan's fact_status
4. Nothing — the assertion is unsupported

Ranks 3 and 4 cannot verify a statistic or quote. Only ranks 1-2 can.
